# Claude instructions for this repo

See `AGENTS.md` for the framework rules.

## Commit authorship

Author every commit as the repo owner so the work counts on his GitHub profile:

```
git -c user.name="Vitaliy Pikalo" -c user.email="pikalo.vitaliy@gmail.com" commit ...
```

Keep the `Co-Authored-By: Claude ...` trailer on commits Claude wrote. Use the real commit time; never backdate or rewrite dates.
